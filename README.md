# Packman

1980年のナムコのアーケードゲーム(パックマン)へのトリビュートとして、公開技術文書に基づき
**完全オリジナルコード**でゲームプレイを忠実に再現した Web ゲームです。ブラウザだけで動作します。

## 遊び方

- `index.html` をブラウザで開くだけで動きます(ローカルサーバ推奨: `python3 -m http.server`)。
- **ENTER / SPACE / タップ**: ゲームスタート
- **矢印キー / WASD / スワイプ**: 移動
- **M**: ミュート切替

## 再現している要素

- 224x288・8pxタイル格子の迷路(ペレット240個+パワーエサ4個)、60Hz固定タイムステップ
- 4体のゴーストの個別AI:
  - 赤(追跡型) / ピンク(4タイル先回り型) / 水色(赤との対称ベクトル型) / オレンジ(距離8タイル閾値型)
  - ピンク・水色の「上方向時に左へずれる」オリジナル実機由来の計算のクセも再現
- スキャッター/チェイスのレベル別切替スケジュールと切替時の強制反転
- レベル別スピードテーブル(通常/イジケ/トンネル/Cruise Elroy)
- ゴーストハウスの放出ロジック(個別ドットカウンタ、ミス後のグローバルカウンタ、無食時タイマー)
- パワーエサ、ゴースト食い連鎖 (200/400/800/1600)、フルーツ(70/170個目で出現)
- コーナリング(交差点手前からの斜め移動)、タイル一致方式の当たり判定(原作同様の「すり抜け」も発生)
- ペレットを食べた際の1フレーム停止(パワーエサは3フレーム)
- コーヒーブレイク(カットシーン)3種
- **レベル256のキルスクリーン**: レベルカウンタの8bitオーバーフローにより画面右半分が
  文字化けし、ドット不足でクリア不能になる有名なバグを再現
- Web Audio によるサウンド(ワウカ音、サイレン5段階、イジケ音、目玉帰還音など)

## 忠実度の限界(既知の差異)

- 乱数系列が原作と異なるため、原作の「パターン攻略」はそのまま通用しません。
- 一部の演出タイミングは近似値です。
- グラフィック・サウンドはすべてオリジナルに作り起こした近似アセットです
  (ROM由来のデータ・波形・スプライトは一切使用していません)。スタート時のジングルも
  当時のスタイルを模したオリジナル曲です。

## 事前調査の要約 (完全再現は可能か?)

実装に先立ち、ROM・基板情報の公開状況を調査しました。

1. **基板ハードウェアは詳細に文書化済み** — Z80 CPU、メモリマップ (ROM 0x0000-0x3FFF /
   RAM 0x4000-0x4FFF / I/O 0x5000-)、タイル+スプライトのビデオ、Namco WSG 3声サウンド。
   Chris Lomont の *Pac-Man Emulation Guide* を典拠に複数の独立エミュレータが実装されています。
2. **ROM イメージは著作権保護されており再配布不可** — オープンソースのエミュレータであっても
   全プロジェクトが ROM 非同梱(ユーザー供給必須)。ゲームロジック自体が ROM 内にあるため、
   エミュレータ方式では著作権問題を回避できません。
3. **ゲームロジックは公開仕様書レベルで文書化済み** — Jamey Pittman *The Pac-Man Dossier* 等に
   ゴーストAI・速度・タイマー・バグまで記載されており、ROM を使わないフルスクラッチ再現の
   実証例も存在します (shaunlebron/pacman など)。
4. **結論** — 公開文書のみから「プレイ体験として原作と区別が難しい」忠実再現は可能。
   ビット単位の同一挙動(同一乱数系列など)までは不可能。本リポジトリは前者のアプローチです。

主な参考資料:

- Jamey Pittman, *The Pac-Man Dossier* (ゲームロジック仕様)
- Chris Lomont, *Pac-Man Emulation Guide* (基板ハードウェア仕様)
- 公開実装例: shaunlebron/pacman, frisnit/pacman-emulator, Justin-Credible/pac-man-emulator
