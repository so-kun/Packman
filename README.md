# Packman

1980年のナムコのアーケードゲーム(パックマン)へのトリビュートとして、ゲームプレイを
公開技術文書から再実装し、**グラフィック・色・サウンド波形は実機のROM/PROMデータ**を
用いて再現した Web ゲームです。ブラウザだけで動作します。

## 遊び方

- `index.html` をブラウザで開くだけで動きます(ローカルサーバ推奨: `python3 -m http.server`)。
- **5 / C**: コイン投入(クレジット加算)。実機同様、クレジットが無いとスタートできません
- **ENTER / SPACE**: スタートボタン
- **タップ** (モバイル): クレジットが無ければコイン投入、あればスタート
- **矢印キー / WASD / スワイプ**: 移動
- **M**: ミュート切替

## 再現している要素

### 見た目と音 — 実機のROM/PROMデータ

- タイルROM `pacman.5e` (8x8を256枚) とスプライトROM `pacman.5f` (16x16を64枚) の実データ。
  文字・迷路・パックマン・ゴースト・フルーツ・スコア表示はすべてこのROMの絵です
- カラーPROM `82s123.7f` とパレットPROM `82s126.4a` の実内容。抵抗ラダーDACを再現しており、
  青だけが2bitチャンネルで飽和が低いという実機の非対称もそのまま出ます
- サウンド波形PROM `82s126.1m` の実内容 (8波形 × 32サンプル × 4bit)。Namco WSG を
  20bitアキュムレータ・96kHz・4bit音量までモデル化して鳴らしています
- スタート時のジングルと死亡音は、**実機のサウンドレジスタ書き込みをキャプチャしたダンプ**を
  そのまま再生しています

### ゲームロジック — 公開文書からの再実装

- 224x288・8pxタイル格子の迷路(ペレット240個+パワーエサ4個)、60Hz固定タイムステップ
- 4体のゴーストの個別AI:
  - 赤(追跡型) / ピンク(4タイル先回り型) / 水色(赤との対称ベクトル型) / オレンジ(距離8タイル閾値型)
  - ピンク・水色の「上方向時に左へずれる」オリジナル実機由来の計算のクセも再現
- スキャッター/チェイスのレベル別切替スケジュールと切替時の強制反転
- レベル別スピードテーブル(通常/イジケ/トンネル/Cruise Elroy)
- ゴーストハウスの放出ロジック(個別ドットカウンタ、ミス後のグローバルカウンタ、無食時タイマー)
- パワーエサ、ゴースト食い連鎖 (200/400/800/1600)、フルーツ(70/170個目で出現)
- コーナリング(交差点手前からの斜め移動)、タイル一致方式の当たり判定(原作同様の「すり抜け」も発生)
- ペレットを食べた際の1フレーム停止(パワーエサは3フレーム)
- コーヒーブレイク(カットシーン)3種
- **レベル256のキルスクリーン**: レベルカウンタの8bitオーバーフローにより画面右半分が
  文字化けし、ドット不足でクリア不能になる有名なバグを再現。化けた画面は実際の
  タイル番号・カラーコードで描いているため、原作同様に文字・スコア片・フルーツ・
  迷路の破片が入り混じります

## 忠実度

どこが実データで、どこが文書からの再現で、どこがまだ推測なのかは
**[docs/fidelity-checklist.md](docs/fidelity-checklist.md)** に一覧しています。

主な残りの差異:

- **乱数系列が原作と異なります**。原作のPRNG状態はプログラムROMの中にあり、本プロジェクトは
  それを実行しないため、原作の「パターン攻略」はそのまま通用しません
- **サイレンのレベル別変化**は推測です。波形・音量・24tick周期は実機の値ですが、
  段階ごとの音程と速さの上がり方は耳合わせです
- **目玉帰還音・パワーエサ音・エクステンド音・コイン音**はレジスタのキャプチャが存在しないため、
  ROM波形を使いつつ輪郭は耳合わせです
- **コーヒーブレイクの曲**もキャプチャが無いため、実機の音色によるオリジナル曲です

## ROMデータについて

`src/romdata.js` は生成物です。[floooh/pacman.c](https://github.com/floooh/pacman.c) (MIT)
が埋め込んでいるROM/PROMダンプから抽出しています。再生成するには:

```sh
git clone --depth 1 https://github.com/floooh/pacman.c /tmp/pacman.c
python3 tools/extract-rom-data.py /tmp/pacman.c/pacman.c
```

プログラムROM(ゲームロジック本体)は使用していません。エミュレータ方式であれば原作と
ビット単位で同一の挙動(同一乱数系列を含む)が得られますが、プログラムROMの同梱が必要に
なるため採っていません。本プロジェクトはロジックを再実装し、ROMデータは
**文書からは導けないもの — 絵・色・音の波形 — に限って**使用する方針です。

## 開発

```sh
node --test 'test/*.test.mjs'      # ROMデコードとサウンド生成のテスト
node tools/dump-gfx.mjs gfx.png    # デコードしたタイル/スプライトを画像に出力
node tools/shots.mjs shots         # ヘッドレスブラウザで画面キャプチャ (要 playwright)
```

主な参考資料:

- Jamey Pittman, *The Pac-Man Dossier* (ゲームロジック仕様)

- floooh/pacman.c (ROM/PROMダンプ、サウンドレジスタのキャプチャ)
